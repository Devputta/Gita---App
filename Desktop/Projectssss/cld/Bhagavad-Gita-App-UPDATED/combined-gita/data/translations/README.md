# Translation content

Supported translation languages are exactly Kannada, Hindi, and English. Sanskrit is stored as the original verse text.

Each published record should contain:
- verseId
- language
- text
- source
- translator
- publisher
- license
- sourceUrl
- notes
- reviewStatus = PUBLISHED

The app does not scrape websites or ship copyrighted translations. Add only translations for which the project has permission/licensing, or original translations created for this project and reviewed by an administrator.

The local JSON files are intentionally empty until licensed/reviewed translation content is supplied.
